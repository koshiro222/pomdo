# 認証は Google OAuth 単一プロバイダに絞る

一般公開プロダクトだが、v1 のログイン手段は Google OAuth のみとする。パスワード認証と Magic Link は持たない。未ログインでの利用は匿名アカウント（[[0002-anonymous-accounts-for-sync]]）で担保するため、ログインの役割は「匿名アカウントを Google に結合してデバイス跨ぎ・永続化を有効にする」ことに限られる。

## 背景

旧実装は Google OAuth ＋ Email/Password を持っていたが、パスワードリセットとメール検証は `console.log` だけの未実装で、実質動かない UI が残っていた。

## 理由

- パスワード認証はハッシュ管理・リセットフロー・メール検証と付随コストが大きく、旧実装でそこが破綻していた。
- Magic Link もメール送信基盤を要する。Google 単一なら v1 は認証メールが一切不要になり、Edge ランタイム継続（[[0001-stay-on-cloudflare-pages-edge]]）の制約とも噛み合う。
- Google で来たユーザーはメール検証済み扱いにでき、独立した検証フロー画面が不要。

## 結果

- Google アカウントを持たない／使いたくないユーザーを取りこぼす。需要が見えた段階で Magic Link を追加する（その時点でメール送信基盤と本 ADR を見直す）。
