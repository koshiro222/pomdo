# Focus Session を集中実績の単一の真実源とし、非正規化カウンタを持たない

タスクごとの「完了ポモドーロ数」や「Focused Days（集中した日の累積）」といった集計値は、テーブルに保持せず `focus_sessions` から都度クエリで算出する。

## 背景

旧実装は `todos.completed_pomodoros` という非正規化カウンタを持ち、セッション記録との二重管理になっていた。また統計取得が直近30件に制限され、週次・月次集計が古いデータを取りこぼすバグがあった。

## 理由

- v1 の集計は「あるユーザーの completed な work セッションを数える／日付で DISTINCT する」程度で、専用テーブルやカウンタを正当化する規模ではない。
- 非正規化カウンタは中断セッションの扱い・削除・タイムゾーン再集計でズレやすく、旧実装で実際にズレていた。
- Focus Session を唯一の記録点にすれば、振り返り・進捗表示・Focused Days がすべて同じ源から導出され、矛盾しない。

## 結果

- 集計クエリは `focus_sessions` にインデックス（`user_id`, `task_id`, `completed_at`）を張って対応する。
- パフォーマンスが問題になる規模に達したら、そのとき初めて投影テーブル／マテリアライズドビューを検討する。将来「最適化」としてカウンタ列を足そうとする者は、まずこの ADR を読むこと。
