# タイマーに一時停止を設けない

Focus Session のタイマーは絶対時刻方式（残り時間 = `endsAt - now`、[[0007-absolute-time-timer]]）で実装し、実行中の一時停止（pause / resume）を持たない。実行中の操作は「ストップ（経過分を記録して区切る）」のみとする。

## 背景

旧実装のタイマーは pause / resume を持ち、`remainingSecs` をクライアントで 1 秒ずつ減算していた。pause は「離席するから一旦止める」「気が散ったから止める」を誘発し、1 本の Focus Session がずるずると引き延ばされ、実測時間と体感がずれていた。

## 理由

- 絶対時刻方式と pause は本質的に相性が悪い。pause 中は `endsAt` を停止時間ぶん後ろへずらす必要があり、タブを閉じた状態での pause・複数タブ・日跨ぎまで考えると状態管理が急激に複雑になる。
- ポモドーロ技法の原則は「割り込みが入ったらそのポモドーロは中断（void）する」であり、pause はこの原則に反する。
- ADHD 当事者向けとして、「今のセッションは生きているか、死んでいるか」の二値が明確な方が判断負荷が低い。中間状態（一時停止中）は迷いを生む。

## 結果

- 離席・割り込み時はユーザーが「ストップ」を押す。経過 60 秒以上なら中断セッション（`completed_at = null`, `duration_secs = 実測`）として記録され、「合計集中時間」には寄与する。60 秒未満は記録しない。
- 「ちょっとだけ止めたい」という要望が強く出た場合は、pause ではなく「セッションを区切って、すぐ次の 1 本を始める」導線の改善で応じる。将来 pause を実装しようとする者は、まずこの ADR と [[0007-absolute-time-timer]] を読むこと。
